# Quantum Teleportation with Qiskit
Implementation of a quantum teleportation circuit using Qiskit and a quantum circuit simulator.
# Overview
This project demonstrates the quantum teleportation protocol using a 3-qubit quantum circuit.
The circuit prepares a quantum state, creates an entangled pair, performs the teleportation protocol, measures two qubits, and applies classically controlled corrections to transfer the original quantum state to the third qubit.
# Protocol
The implementation follows the main steps of quantum teleportation:
Prepare the quantum state to be teleported.
Create an entangled pair of qubits.
Perform the required CNOT and Hadamard operations.
Measure the first two qubits.
Apply X and Z corrections based on the measurement results.
Simulate the circuit and visualize the measurement outcomes.
